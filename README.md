# Data Science Projects

This is the code for the two questions for my Principles of Data Science class
## 1. Frailty project
This project looks at health data. It checks age, height, weight, grip strength, and frailty.

Folder: question_one

## 2. Student score project
This project looks at student test scores. It checks math, reading, writing, lunch type, and test prep.

Folder: question_two

## Common folders
- data_raw: original data
- data_clean: cleaned data and metadata
- results: charts and reports
- src: Python code
- There is Meta data in each data_clean folder
